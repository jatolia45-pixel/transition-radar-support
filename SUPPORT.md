# Getting help safely

For general, non-sensitive contact, email [mail-jatolia45@gmail.com](mailto:mail-jatolia45@gmail.com). Do not include passwords, tokens, account identifiers, private research or other sensitive information.

Choose a bug report or support question from the Issues tab. Check existing public issues using only non-sensitive search terms.

Describe the expected behavior, what happened and minimal steps using fictional data. Include the date/time and host/plugin version if known. Remove personal details from any screenshot.

Do not include tokens, passwords, cookies, OAuth authorization codes, authentication headers, user/account identifiers or private watchlist content. Do not attach raw network traces, exported conversations or server logs.

For private-data access/deletion requests or security vulnerabilities, do not post the details publicly. A dedicated private data-rights/security route, identity-check process and response procedure have not been established. Do not assume the general contact email has a secure or approved workflow for sensitive requests. GitHub issue deletion does not guarantee removal of copies or notifications.

Support availability and response times are not guaranteed by these documents. The service uses authentication and hosting providers with their own availability and quota limits.
