# Transition Radar support

Public support for Transition Radar, a research workflow with an authenticated personal watchlist and retained research history.

Public listing name requested by the publisher: **DJ Nawal**. Original package attribution: **D.Jatoliya**. These names do not establish a verified legal identity.
General non-sensitive contact: mail-jatolia45@gmail.com. Do not send passwords, tokens, account identifiers, private research, or other sensitive information by email.

Use this repository's Issues tab for non-sensitive questions and reproducible problems. Include what you tried, the approximate time, the visible error and your host/plugin version. Use fictional sample research when describing a problem.

**GitHub issues and attachments are public.** Never post passwords, access tokens, cookies, authorization headers, OAuth codes, account identifiers, private research, full browser captures or raw logs. Crop screenshots to the relevant error and remove personal details. A request ID may help investigation; do not attach the entire request or response.

For uncertain saves, retry the same operation using its original retry key. For revision conflicts, retrieve the current item before revising. Archiving removes an item from the default active watchlist but retains its history; it does not permanently delete it.

The tools save, recall, append observations, revise and archive research. They do not execute purchases or trades, send external messages or continuously monitor the web. Research output can be incomplete or mistaken; verify the evidence before relying on it.

This repository contains support documentation only. It does not contain the service runtime, user records or credentials. No response-time or availability commitment is stated. Private data requests and security reports need an approved private contact method; do not file their details in public issues.
